# Avaliação A2 de Modelagem de Banco de Dados

A A2 (até 5,0) é o projeto em grupo (3 a 5 alunos) do semestre: o banco de dados de uma **organização real** (comércio, ONG, associação, instituição religiosa). Notas: **Entrega 1** (1,6), **Entrega 2** (2,4), **seminário** (0,75) e **avaliação 360°** entre os colegas (0,25). Os requisitos vêm de pesquisa de campo (visita, entrevista, observação); a organização não pode ser fictícia nem trocada entre as entregas.

## Entrega 1 — modelo conceitual (22 a 25/09; turma de segunda, 05/10)

README no GitHub do grupo, seguindo 📚 `00-c_Esqueleto_Entrega_1`:
- Caracterização da organização com evidências de acesso; processos de negócio.
- Requisitos funcionais e não funcionais; regras de negócio.
- Dicionário de dados conceitual (modelo em 📚 `02-03g`), com exemplos sempre fictícios.
- Entidades, atributos e relacionamentos; **DER** em imagem (20%, maior peso) e justificativa técnica.
- Registro obrigatório do uso de IA (ou declaração de que não usou).

## Entrega 2 e seminário (Entrega 2 de 04 a 10/11; seminários de 11 a 17/11)

Modelo lógico normalizado (até a 3FN), script SQL com massa de dados fictícia; no seminário, o grupo apresenta e defende o projeto. Siga 📚 `00-d_Esqueleto_Entrega_2`.

Itens da Entrega 2: DER revisado; conversão para o modelo lógico com PKs e FKs; normalização (1FN, 2FN, 3FN) justificada; proposta de BI e IA; script SQL completo (CREATE, constraints, INSERT com massa fictícia, SELECT com JOIN, UPDATE, DELETE, consultas gerenciais e de auditoria); repositório com commits ao longo do tempo; registro do uso de IA. Seminário: pitch cronometrado, sem leitura de textos longos, com o SQL rodando e as consultas demonstradas.

## Como ajudar

Não monte o DER, o dicionário, as tabelas nem o script do grupo, e não escolha a organização. Explique com exemplos de uma organização fictícia e devolva perguntas que façam o aluno encontrar o erro no próprio modelo.
